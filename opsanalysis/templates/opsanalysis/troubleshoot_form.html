"某服务访问不了"——关联应用服务器 / supervisor / Nginx / DNS / Jenkins 的只读信号， 汇成一条时间线辅助定位。

运维分析 历史任务
只读排查，绝不执行任何修复动作。 本功能仅关联 应用服务器状态 / supervisor / Nginx 日志 / DNS / Jenkins 构建 等只读信号， 汇聚成时间线，并严格区分：已确认事实、时间关联、推测原因、建议检查。 "同时发生"不等于"因果关系"，推测项均需人工确认。

排查会关联哪些只读信号

全部只读，不下发任何修复动作
  • 应用服务器：目标端口是否监听、应用进程是否存在、CPU/内存、运行时长（疑似刚重启）。
  • Supervisor：程序状态（RUNNING / EXITED / FATAL / BACKOFF）。
  • Nginx：窗口内 access 日志 5xx（502/503/504）计数、error 日志 upstream 错误（connection refused / timed out / no live upstreams）。
  • DNS：域名在各 DNS 服务器的解析结果，是否与登记后端一致。
  • Jenkins：对应 job 最近构建时间/结果/提交，用于把"最近部署"放进时间线。
